# Jad's Concierge Services — Clothing Website

Simple static website for Jad's Concierge Services.

Open `index.html` in a browser to view the site.

Files included: `index.html`, `scripts.js`, `styles.css`, `images/`.

Repository: https://github.com/raphealocran/Jad-s-Concierge-Services

## Quick start

Open the project root and double-click `index.html`, or serve with a simple HTTP server:

```bash
python -m http.server 8000
# then open http://localhost:8000
```

## Notes

- Static site — no build step required.
