# Jad's Concierge Services — Clothing Website

A responsive online shopping website for Jad's Concierge Services (JCS) — fashion, premium human-hair wigs, kitchenware, beauty, and gadgets with clear delivery timelines. Built with HTML, CSS, and JavaScript.

## Features

- Hero section with promotional messaging
- Delivery timeline cards (24–48h local stock, 7–20 day international fashion, 40–45 day bulk imports)
- Product category sections with dynamic product displays
- Image gallery
- Fully responsive layout (desktop, tablet, mobile)
- Accessible navigation (skip link, ARIA labels)

## Tech stack

- HTML5
- CSS3 (custom, no framework)
- Vanilla JavaScript
- Bootstrap Icons (CDN)
- Inter font via Google Fonts

## Project structure

```
├── index.html      # Main page
├── styles.css      # All styling
├── scripts.js      # Interactivity (nav, gallery, etc.)
└── images/         # Product and hero images
```

## Run locally

Open `index.html` in a browser, or serve with a simple HTTP server:

```bash
python -m http.server 8000
# then open http://localhost:8000
```

## Notes

- Static site — no build step required.
